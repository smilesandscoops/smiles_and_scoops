# Smiles & Scoops

Handmade jewelry and crochet flowers — made with heart.

🌐 **Live site:** [mickeymavs1.github.io](https://mickeymavs1.github.io/)

## About

Smiles & Scoops is a small handmade brand selling:
- **Jewelry** — bracelets, necklaces, earrings, rings, and anklets
- **Crochet Flowers** — bouquets, hair clips, keychains, bookmarks, coasters, and wall hangings

Every piece is handmade in small batches. Orders are placed directly via Instagram or WhatsApp.

## Local development

Open `index.html` directly in a browser, or serve the folder with any static server, e.g.:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
